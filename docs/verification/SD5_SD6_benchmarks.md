## ユーザーレビューで発見した課題 (2026-07-25)

1. **立川: 融合世界の1日あたり便数が過大** — 旧側の「年末」「正月」が
   迷い日付 (共有日) で1世界に融合し、特定日①が 28→16▼ (実際は正月 16→16
   不変、年末 16→12)。原則A「同じ日に走らないものを足さない」が融合世界の
   **内部で**破れている。→ SD5c: 世界の定義を「日付毎の有効 service 集合が
   同一の日の同値類 (日付分割)」に精緻化する (中津の冬融合も同根)
2. **しんぐう: 日付ラン表示が「3/1〜3/30 ほか (全245日)」** — cell meta の
   日付リストが上限30日で切られてからラン圧縮されるため。→ サーバー側で
   ラン圧縮してから格納。あわせて**年境 (12/31|1/1) でだけランを分割**、
   それ以外は月を跨いでも連結 (ユーザー指定)
3. **市川三珠線: 運行日なし 1→0▼ に旧世代の (定義上の) 期間を出したい**
4. 甲賀の「火水木金土日①〜③」と「火水木金①〜③」の非統合は仕様
   (day_type ラベル = タブ軸はデータの曜日集合に忠実)。運行日なし = calendar
   に定義はあるが実効運行日ゼロの service (に紐づく便)
